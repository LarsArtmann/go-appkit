The uncomfortable headline

The 2026-10-19 TODO header claimed "everything green" while that same day's origin run already had art-dupl-gate RED. The designed ci-preflight failure had normalized red conclusions: one intentional failure in every run trained the eye to stop reading job lists. Green-by-assumption is how a guard can be born broken and stay broken for six days. The verification culture here is local-first; the session-close ritual was only ever applied when a human-driven wave pushed — daemon and dependabot commits landed on master with nobody looking.

What this session did about it

Every in-tree finding below is FIXED and re-verified in-session: 12/12 modules hermetic build+vet+test -race, 12/12 lint 0 issues, 8/8 guards green, pin-drift green on the new httputil v1.6.0 pin, actionlint green, the CI install path proven against a fresh module cache. The wave awaits the owner push and the tip-CI verify ritual — no local verdict can prove a runner.

art-dupl-gate was born broken and never ran its check once

.github/workflows/ci.yml · art-dupl-gate job

The install used the bare module path go install github.com/LarsArtmann/art-dupl@<pseudo-version>. The module root carries no Go package — the binary lives in cmd/art-dupl — so every runner run died at install with "found, but does not contain package" ~19 seconds in. The job shipped 2026-10-19 with a "clean-runner-proven" claim that was false: any real clean-runner install would have shown the error. Six days red on origin; every dependabot PR blocked by it.

Fix Install path re-pointed to cmd/art-dupl@v0.9.1-0.20261017225421-93432fd910fb, proven by a fresh-GOMODCACHE proxy build (BUILD_OK + working binary). Local guard green against the committed baseline. The false "clean-runner-proven" claim is corrected in AGENTS.md.

Fixed in tree

Integration flake: OS port reuse beat the freeAddr probe

integration/integration_test.go:54 · composition_contract_test.go:85

On the 10-24 runner, TestVersionAndMetricsComposeWithDefaultHealth failed with listen_failed EADDRINUSE: two parallel tests each picked a port via listen(:0) → close, and the OS handed the same just-closed ephemeral port to both before either Service bound. The classic TOCTOU — the rebind-after-close probe alone cannot catch it because both picks complete before any bind.

Fix freeAddr now keeps a process-wide issued-registry (a repeat addr is redrawn) AND probes an instant rebind (external steals redraw). Suite green hermetic -race -count=1. Documented in AGENTS (the stale "freePort()" claim is corrected — root tests bind localhost:0 directly and never had this race).

Doc trees (doc/ vs docs/, fixed); lint truth (local 0-issues vs CI never-checks, fixed with fleet-lint); port-picking (root binds :0 directly, integration hand-rolled freeAddr — now hardened in place, full dedup parked on a core train); history (TODO header vs status index, fixed); release truth vs tag reality (httputil v1.6.0's replace vs the family rule — ask drafted).
