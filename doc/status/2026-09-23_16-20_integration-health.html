05What We Should Improve

Guards must be visible under a red CI

The go-directives drift guard exists and works — it failed today's run, and the drift shipped anyway because every run is red. A red baseline destroys every signal. Fix the secret first; then consider making guard jobs required checks so a red master is always an event.

Auto-commit daemon vs go directives (structural)

Twice in six days the daemon raised the root go directive. The daemon is not CI-aware. A pre-commit/post-commit hook that rejects go-directive bumps outside an explicit train would kill this class at the source instead of detecting it after push.

Dependabot PRs will always be red on ssh-agent

Dependabot PR runs cannot read Actions secrets (fork rules), so every dependency PR shows a failure that is not a regression. Gate the ssh-agent step on github.event_name == 'push' (or reuse cache for PRs) so PR signal means something.
